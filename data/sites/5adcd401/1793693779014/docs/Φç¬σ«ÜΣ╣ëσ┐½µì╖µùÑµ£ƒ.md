# 自定义快捷日期

在单个日期筛选器上增加快捷日期。编辑里保存之后，预览的日期下拉才出现这些按钮。可以把某一条快捷日期设为默认值。

## 硬性规则

1. 如果启用了快捷日期，并且指定了某个日期作为默认值，则这条快捷日期的优先级大于精确、相对等其他默认值。打开筛选器时按这条计算。未启用快捷日期时，仍使用精确或相对默认值。

## 1. 编辑

沿用「新建日期」。

| 区域 | 规则 |
| --- | --- |
| 控制器标题 | 必填。预览里作为筛选器名称。未填写不能保存。 |
| 日期类型 | 日期。 |
| 默认值 | 精确：一个具体日期，格式 YYYY-MM-DD。相对：前或后 N 天，N 为不小于 0 的整数。快捷：在操作列把某一条快捷日期设为默认值后，这里改为「快捷」并带上该条名称。快捷日期已启用且这一条带 `default: true` 时，按硬性规则 1，优先于精确和相对。改回精确或相对后，去掉 `default`。 |
| 对应关系 | 可选，填写关联字段。 |
| 是否显示 | 显示、隐藏、条件。隐藏时预览不展示日期框。 |
| 快捷日期 | 是否启用，默认启用。关闭后预览下拉不显示左侧快捷按钮，已配置的条目和默认值仍保留。每条是一个时间点，最多 7 个。标题右侧是「新增」。点它在表格末尾增加一行，年份、月份、日和名称都在这一行里改。年份默认当年，选项同上年、当年、下年，或前 N 年、后 N 年、第 N 年。前 N 年、后 N 年的 N 为 1–36，相对当前年。第 N 年的 N 为 1900–2100，指这一年。月份取上月、当月、下月，或前 N 月、后 N 月、第 N 月。前 N 月、后 N 月的 N 为 1–36，相对该年的当前月。第 N 月的 N 为 1–12，指该年的这个月。日取上日、当日、下日、最后一天，或前 N 日、后 N 日、第 N 日。上日、当日、下日相对该月里与今天相同的那一天，该月没有这一天时取最后一天。最后一天就是该月最后一天，不填写号数。前 N 日、后 N 日的 N 为 1–366，从这一天往前或往后数。第 N 日的 N 为 1–31，指该月的这一天；该月没有这一天时，取最后一天。名称按规则自动生成，可以改。满 7 个后「新增」消失。名称不能为空，也不能重复。操作列有「设置为默认值」和「删除」。同一时间只有一条是默认值，该行改为「取消默认」。点「取消默认」后去掉 `default`，默认值回到相对。删掉这条时同样回到相对。 |
| 保存 | 写入当前配置并提示「已保存」。未保存的修改不影响预览。 |

名称自动生成规则：

- 年份为当年时不写入名称。日写在月份后面：上月第 1 日、当月当日、下月前 3 日、第 6 月后 2 日。
- 其他年份写在月份前面：上年上月当日、前 2 年第 6 月第 15 日、第 2024 年下月第 15 日。
- 手改后可以写成「下月末」。

## 2. 预览

日期框是单日选择器，交互参照 Ant Design DatePicker。

- 启用快捷日期时，点日期框，下拉左侧是快捷按钮，右侧是日历。未启用时只有日历。底部有「今天」。
- 点快捷按钮，填入按当天算出的日期，日历定位到这一天，然后关闭下拉。
- 也可以直接点日历上的某一天，或点「今天」。
- 打开预览时，输入框里是默认值算出的日期。默认值是快捷日期时，按这条快捷日期计算。精确日期未填时，输入框为空。
- 筛选器设为隐藏时，预览只提示「筛选器已隐藏」，不展示日期框。

## 3. 示例

快捷日期不保存算好的 `YYYY-MM-DD`。每条保存下面这个结构。打开筛选器或设为默认值时，以当天为基准，用 moment.js 按「年 → 月 → 日」算出一个确切日期。基准日变了，结果跟着变。

### 保存结构

```json
{
  "name": "名称",
  "default": true,
  "year": { "op": "current" },
  "month": { "op": "prev" },
  "day": { "op": "nth", "n": 1 }
}
```

- `name`：显示名称。可按规则自动生成，也可以手改。
- `default`：可选。`true` 表示这一条是筛选器的默认值。同一组里最多一条为 `true`，其余不写这个属性。点「取消默认」、改回精确或相对，或删掉这一条时，去掉 `default`。
- `year`、`month`、`day`：各是一个对象，必有 `op`。
- `n`：只在 `op` 为 `ago`、`later`、`nth` 时出现，且为正整数。`current`、`prev`、`next`、`last` 只写 `op`，不写 `n`。

### op 枚举

年只有这 6 个 `op`。基准是当天所在年。

| op | 界面 | n | 含义 |
| --- | --- | --- | --- |
| current | 当年 | 无 | 不移动 |
| prev | 上年 | 无 | 减 1 年 |
| next | 下年 | 无 | 加 1 年 |
| ago | 前N年 | 1–36 | 减 n 年 |
| later | 后N年 | 1–36 | 加 n 年 |
| nth | 第N年 | 1900–2100 | 公历年 n |

月只有这 6 个 `op`。基准是年规则算完之后的那个月。

| op | 界面 | n | 含义 |
| --- | --- | --- | --- |
| current | 当月 | 无 | 不移动 |
| prev | 上月 | 无 | 减 1 月 |
| next | 下月 | 无 | 加 1 月 |
| ago | 前N月 | 1–36 | 减 n 月 |
| later | 后N月 | 1–36 | 加 n 月 |
| nth | 第N月 | 1–12 | 该年的第 n 月 |

日有这 7 个 `op`。先确定锚点：该月里与今天相同的日号；该月没有这一天时，锚点取该月最后一天。

| op | 界面 | n | 含义 |
| --- | --- | --- | --- |
| current | 当日 | 无 | 停在锚点 |
| prev | 上日 | 无 | 锚点减 1 天，可以跨月 |
| next | 下日 | 无 | 锚点加 1 天，可以跨月 |
| ago | 前N日 | 1–366 | 锚点减 n 天，可以跨月 |
| later | 后N日 | 1–366 | 锚点加 n 天，可以跨月 |
| nth | 第N日 | 1–31 | 该月的第 n 日；没有这一天时取该月最后一天 |
| last | 最后一天 | 无 | 该月最后一天。不填写号数，也不用知道这个月有几天 |

### 用 moment.js 计算

从 `moment().startOf('day')` 得到 cursor，并记住当天的日号。然后按顺序改 cursor：

1. 年。`prev` 用 `subtract(1, 'year')`，`next` 用 `add(1, 'year')`，`ago` 用 `subtract(n, 'year')`，`later` 用 `add(n, 'year')`，`nth` 用 `year(n)`。`current` 不动。
2. 月。单位换成 `'month'`。`nth` 用 `month(n - 1)`，因为 moment 的月份从 0 开始，第 8 月是 7。
3. 日。锚点日号是 `Math.min(当天日号, cursor.daysInMonth())`，先 `date(锚点日号)`。`prev` 再 `subtract(1, 'day')`，`next` 再 `add(1, 'day')`，`ago` 再 `subtract(n, 'day')`，`later` 再 `add(n, 'day')`。`nth` 改为 `date(Math.min(n, cursor.daysInMonth()))`。`last` 改为 `date(cursor.daysInMonth())`。
4. 用 `format('YYYY-MM-DD')` 得到确切日期。

下面的例子都以 2026-11-03 为当天。

上月第1日，并设为默认值。打开时按它算出 2026-10-01：

```json
{
  "name": "上月第1日",
  "default": true,
  "year": { "op": "current" },
  "month": { "op": "prev" },
  "day": { "op": "nth", "n": 1 }
}
```

下月末，算出 2026-12-31：

```json
{
  "name": "下月末",
  "year": { "op": "current" },
  "month": { "op": "next" },
  "day": { "op": "last" }
}
```

2024年第8月最后一天，算出 2024-08-31。年、月是确定的，日用 `last`，不随当天变化，也不依赖 8 月有 31 天：

```json
{
  "name": "2024年第8月最后一天",
  "year": { "op": "nth", "n": 2024 },
  "month": { "op": "nth", "n": 8 },
  "day": { "op": "last" }
}
```

上月当日，算出 2026-10-03：

```json
{
  "name": "上月当日",
  "year": { "op": "current" },
  "month": { "op": "prev" },
  "day": { "op": "current" }
}
```

当月后2日，从 11 月 3 日往后 2 天，算出 2026-11-05：

```json
{
  "name": "当月后2日",
  "year": { "op": "current" },
  "month": { "op": "current" },
  "day": { "op": "later", "n": 2 }
}
```

当月前3日，从 11 月 3 日往前 3 天，算出 2026-10-31：

```json
{
  "name": "当月前3日",
  "year": { "op": "current" },
  "month": { "op": "current" },
  "day": { "op": "ago", "n": 3 }
}
```

前2年第6月第15日，算出 2024-06-15：

```json
{
  "name": "前2年第6月第15日",
  "year": { "op": "ago", "n": 2 },
  "month": { "op": "nth", "n": 6 },
  "day": { "op": "nth", "n": 15 }
}
```

第2026年2月第31日，2 月没有 31 日，取最后一天，算出 2026-02-28：

```json
{
  "name": "第2026年2月第31日",
  "year": { "op": "nth", "n": 2026 },
  "month": { "op": "nth", "n": 2 },
  "day": { "op": "nth", "n": 31 }
}
```

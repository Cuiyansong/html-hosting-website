# 标签管理

入口：系统管理 → 标签管理。由管理员统一维护标签字典，供保存仪表板时选择。无「仪表板标签管理」权限的角色不展示该菜单。

## 列表

| 区域 | 规则 |
| --- | --- |
| 页面标题 | 标题「仪表板标签」，说明「统一维护仪表板的标签，供保存仪表板时选择」；右侧主按钮「新建标签」。 |
| 筛选 | 标签名称输入框（占位「请输入标签名称」）+「查询」「重置」。回车即查询。名称为 `contains` 模糊匹配，忽略首尾空格。 |
| 列表列 | 标签名称、关联仪表板、创建人、创建时间、更新时间、操作。 |
| 关联仪表板 | 数字可点击，下钻到已按该标签筛选的仪表板列表。下钻页不单独占场景位。 |
| 操作 | 「编辑」「删除」。删除为危险色。 |
| 排序 | 默认按更新时间倒序；同一秒内按 id 倒序，保证分页稳定。新建或编辑成功后该行回到首位并高亮 1.5 秒。 |
| 分页 | 默认 20 条/页，展示总数。不足 1 页时仍展示总数，隐藏翻页按钮。 |
| 空状态 | 无标签时展示「还没有标签」和「新建第一个标签」。搜索无结果时展示「未找到匹配的标签」和「清空筛选」。 |

## 新建

点击「新建标签」打开居中弹窗，宽度 440px，只有「标签名称」一项。

- 必填，单行输入，最长 20 个字符，右下角实时显示 `n/20`。
- 允许中文、字母、数字、下划线、中划线和中间空格；禁止 `/ \ : * ? " < > |` 以及 emoji。
- 输入时只截断长度。失焦和提交时做唯一性校验，错误展示在输入框下方，不弹 toast。
- 全租户内名称唯一，比较时忽略首尾空格且不区分大小写。
- 提交中按钮进入加载并禁用。成功后关闭弹窗，toast「标签创建成功」，列表刷新。
- Esc 或点击遮罩可关闭。已输入内容时不二次拦截。

## 编辑

弹窗标题为「编辑标签」，名称预填当前值。顶部提示：「修改名称后，已关联的 N 个仪表板将同步展示新名称。」

名称未变化时不发请求，直接关闭。有变化时走同一套唯一性校验，并排除自身 ID。改名通过标签 ID 关联，所有已绑定仪表板同步展示新名称。

## 删除

| 场景 | 确认文案 |
| --- | --- |
| 关联数为 0 | 「删除后不可恢复，确定删除标签「{name}」吗？」 |
| 关联数大于 0 | 「标签「{name}」已被 N 个仪表板使用，删除后这些仪表板将不再展示该标签，仪表板内容不受影响。」 |

删除为软删除（`deleted=1`），绑定关系同步失效。仪表板本身、目录和权限不受影响。已删除标签不可再次绑定。成功后移除该行并 toast；当前页被删空时回到上一页。

## 业务规则

- 标签按租户隔离，跨租户不可见、不可复用。
- 单个仪表板最多绑定 10 个标签，最少 0 个。
- 删除保留 ID，避免历史操作日志断链。

# 保存时打标

在仪表板编辑态点击「保存」后，保存弹窗中增加「风险级别」和「标签」。标签非必填。编辑已有仪表板时，回显当前已绑定的标签。

风险级别与标签互不影响。级别是仪表板自身的资源级别，下载审批用它和流程门槛比较；改级不在本弹窗完成。

## 风险级别

位于「保存位置」之后、「标签」之前。此处只读，不可修改。

| 元素 | 规则 |
| --- | --- |
| 控件 | 浅灰只读容器内展示等级徽标（如「2 级 · 内部」）、锁图标，以及「改级请到系统管理 → 风险控制」。不可点击，无下拉，光标为箭头。 |
| 默认值 | 新建固定为 1 级 · 公开，随仪表板落库。弹窗内不能改。 |
| 影响提示 | 徽标下说明「下载时将命中 k 条启用流程（门槛 ≤ n 级）」。k 为 0 时改为「按当前生效的流程，下载无需审批」。数字来自分级统计接口。 |
| 编辑回显 | 回显当前级别，同样只读。存量未定级的仪表板按 1 级展示。 |
| 提交 | 与仪表板、标签同一次请求提交 `riskLevel`：新建为 1 级，编辑回传原值。不单独开接口。 |
| 改级入口 | 只有「系统管理 → 风险控制」可以改级。 |

资源侧徽标不带 `≥`。`≥3 级` 只用于流程门槛，两种写法不能混用。

## 标签

非必填，最多 10 个。

| 元素 | 规则 |
| --- | --- |
| 选择方式 | 标签以 chip 平铺，点击切换选中。已选 chip 为品牌色描边、浅底和勾选图标。 |
| 已选计数 | 右上角展示「已选 n/10」，随点击变化。达到上限后，未选中的 chip 置灰，并 toast「最多选择 10 个标签」。 |
| 内联新建 | 标题行提供「＋ 新建标签」。展开输入框和「添加」，成功后新标签以选中态出现在列表末尾，并写入标签字典。输入了名称但没点「添加」就点「保存」时，先自动创建再保存，不丢弃。 |
| 清空 | 已选大于 0 时展示「清空」，一键取消全部选中。 |
| 字典为空 | 展示「暂无可用标签，先去创建」。「＋ 新建标签」仍然可用，不必离开保存流程。 |
| 提交 | 标签作为 `tagIds[]`，与仪表板保存在同一次请求、同一事务中提交。任一失败则整体回滚。 |

无仪表板编辑权限时，标签区只读。

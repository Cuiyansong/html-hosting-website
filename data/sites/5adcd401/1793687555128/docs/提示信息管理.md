# 提示信息管理

入口：系统管理 → 提示信息管理，进入文档管理主界面。主界面用页签切换「文档管理」和「关联管理」，默认停在文档管理。仅系统管理员可维护。能打开对应仪表板或图表的人，可以在右上角看到说明并阅读。

## 需求提纲

> 1 - 创建说明文档
> 2 - 关联文档到仪表板或者图表
> 3 - 在仪表板和图表的右上角，显示icon，当点击icon时，右侧弹出抽屉，展示说明文档
> 4 - 说明文档支持markdown格式编辑和预览
> 5 - 文档字数不超过2000字
> 6 - 一篇文档可关联多张仪表板和多个图表。一张仪表板、一个图表都只能关联一篇文档。已被关联的仪表板或图表，不能再关联其他文档
> 7 - 文档可编辑和删除（删除时需要提示确认）
> 8 - 管理端可以设置两个模块：文档管理和关联管理

## 1. 文档管理

维护说明文档本身。一篇文档可以挂到多张仪表板、多个图表。一张仪表板、一个图表都只能挂一篇文档。


| 区域     | 规则                                                  |
| ------ | --------------------------------------------------- |
| 页面标题   | 页签「文档管理」「关联管理」，默认「文档管理」。当前为文档管理时，右侧主按钮「新建文档」。       |
| 筛选     | 文档名称输入框（占位「请输入文档名称」）+「查询」「重置」。回车即查询。名称为包含匹配，忽略首尾空格。 |
| 列表列    | 文档名称、关联资源数量、更新人、更新时间、操作。                            |
| 关联资源数量 | 已关联的仪表板数与图表数之和。为 0 时展示「—」。                          |
| 操作     | 「编辑」「删除」。删除为危险色。                                    |
| 排序     | 默认按更新时间倒序。新建或编辑成功后该行回到首位。                           |
| 空状态    | 无文档时展示「还没有说明文档」和「新建文档」。搜索无结果时展示「未找到匹配的文档」和「清空筛选」。   |




### 新建与编辑

点击「新建文档」或「编辑」打开同一弹窗。新建标题为「新建文档」，编辑标题为「编辑文档」，并回显名称和正文。


| 字段   | 规则                                  |
| ---- | ----------------------------------- |
| 文档名称 | 必填，1–40 字。租户内不可重复，比较时忽略首尾空格且不区分大小写。 |
| 正文   | 必填。Markdown 源文按字符计，最多 2000，含标记和换行。  |


正文区提供「编辑 / 预览」切换：

- 「编辑」是 Markdown 文本框，右下角实时显示 `n/2000`。
- 「预览」按当前正文渲染，不可在预览里改字。未填写时展示「暂无内容」。
- 超过 2000 字时计数变红，保存按钮不可用。错误留在输入区，不另弹提示。
- 名称为空、正文为空或名称重复时，不能保存，错误展示在对应字段下方。

保存成功后关闭弹窗。新建提示「文档创建成功」，编辑提示「文档已保存」。已关联的仪表板和图表下次打开说明时看到最新正文。名称未改、正文未改时直接关闭，不发请求。

Esc 或点击遮罩可关闭。已修改但未保存时，先确认「有未保存的修改，确定离开吗？」。

### 删除


| 场景  | 确认文案                                                   |
| --- | ------------------------------------------------------ |
| 未关联 | 「删除后不可恢复，确定删除文档「{name}」吗？」                             |
| 已关联 | 「文档「{name}」已关联 N 个仪表板、M 个图表。删除后这些关联一并解除，仪表板和图表本身不受影响。」 |


确认后删除文档及其全部关联。仪表板、图表不删除。成功后移除该行并提示「已删除」。取消则保持原状。

## 2. 关联管理

把已有文档挂到仪表板或图表上。

- 一篇文档可关联多张仪表板、多个图表。
- 一张仪表板、一个图表都只能关联一篇文档。已被某篇文档关联的对象，不能再被其他文档关联，除非先解除原关联。


| 区域   | 规则                                                              |
| ---- | --------------------------------------------------------------- |
| 页面标题 | 同一主界面切换到「关联管理」页签，右侧主按钮改为「新建关联」。不另开页面。                           |
| 筛选   | 对象类型（全部 / 仪表板 / 图表）、对象名称、文档名称。「查询」「重置」靠右，回车即查询。名称均为包含匹配，忽略首尾空格。 |
| 列表列  | 对象类型、对象名称、文档名称、关联时间、操作。                                         |
| 操作   | 「解除」。                                                           |
| 排序   | 默认按关联时间倒序。                                                      |
| 空状态  | 无关联时展示「还没有关联」和「新建关联」。搜索无结果时展示「未找到匹配的关联」和「清空筛选」。                 |




### 新建关联

点击「新建关联」打开弹窗，三步都在同一个弹窗里完成：

1. 先选对象类型：仪表板或图表。切换类型时清空已选对象和已选文档。
2. 选择对象，列表支持按名称搜索。未选对象时不能保存。
3. 选择文档。只列出未删除的文档，支持按名称搜索。未选文档时不能保存。

仪表板和图表使用同一套规则：

- 文档只能选一篇。
- 对象可多选。已被关联的对象仍出现在列表中，置灰不可勾选，并注明「已关联「{文档名称}」」。
- 保存后，每个选中的仪表板或图表都只关联这一篇文档。

成功后关闭弹窗，提示「已关联 N 条，跳过 M 条」，列表刷新。没有选出对象或文档时不关闭，并提示「请选择对象和文档」。若提交时某个对象已被其他文档抢先关联，该对象跳过并计入 M，其余仍然生效。

### 解除

点击「解除」必须确认：「确定解除「{对象名称}」与文档「{文档名称}」的关联吗？对象和文档都保留。」

确认后只删除这一条关系。对象上若已无任何文档，右上角说明图标随之消失。取消则保持原状。

## 查看说明

使用者在仪表板或图表上阅读说明。这里只读，不提供编辑和删除。

- 该对象至少关联一篇文档时，右上角显示说明图标。没有关联时不显示图标，也不占位。
- 点击图标，从右侧滑出抽屉，渲染 Markdown。
- 仪表板和图表都最多关联一篇文档，抽屉直接展示标题和正文。
- 关闭方式：抽屉右上角关闭按钮、点击遮罩、按 Esc。
- 管理端保存文档或解除关联后，已经打开的抽屉不实时改写。下次打开时看到最新正文。



## 权限

- 系统管理员可进入「文档管理」和「关联管理」。无此权限的角色不展示这两个模块。
- 能打开该仪表板或图表的人可以看到说明图标和抽屉，不能从抽屉进入编辑或删除。

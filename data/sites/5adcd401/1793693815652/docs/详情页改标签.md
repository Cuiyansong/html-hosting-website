# 详情页改标签

仪表板详情页展示已绑定的标签和风险级别。改标签不另设入口，和改名称走同一个编辑弹窗。

## 展示

- 标题下方单独一行展示全部标签，不折叠，顺序与保存时一致。
- 无标签时不展示「未打标」占位。
- 标题后展示风险级别徽标，形如 `2 级 · 内部`，不带 `≥`。
- 标签和风险级别各自独立，互不覆盖。

## 修改

- 只有一个入口：点右上「编辑」或标题旁的铅笔，打开与保存相同的弹窗。
- 弹窗中可以增删标签、修改名称。风险级别仍然只读，改级仍走「系统管理 → 风险控制」。
- 保存后标签行即时回写，不需要二次发布。
- 无编辑权限时隐藏「编辑」，标签只读展示。

## 从列表进入

仪表板列表在「所属目录」之后增加「标签」列：

- 最多展示 3 个标签，超出显示 `+N`，悬停展示全部名称。
- 没有标签时展示「—」。
- 筛选区增加标签多选。多个标签之间为「或」，与目录筛选为「与」。
- 左侧目录树顶部固定「仪表板概览」，默认选中并展示全部仪表板。点具体目录后按目录过滤，概览项始终置顶。
- 点「关联仪表板」数字进入的列表，是已按该标签过滤的下钻页，不单独占场景位。
